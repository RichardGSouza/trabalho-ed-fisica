# Trabalho de Educação Fisica

A professora passou criar um jogo cooperativo com foca na comunicação como o trabalho.

O jogo vai ser co-op de 2 players, multiplayer LAN.
O jogo é de plataforma, com puzzles

Ele baseia-se na mecanica da corda e habilidades únicas do jogador.
